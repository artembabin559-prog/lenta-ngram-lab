# Биграммы и триграммы в генерации русскоязычных новостей

Лабораторная работа № 11 по компьютерной лингвистике. Обе модели обучаются на 500 предложениях из 102 спортивных новостей Lenta.ru.

[Разбор проекта и кода для защиты](ОБЪЯСНЕНИЕ_ПРОЕКТА.md) · [Отчёт (Word)](report.docx) · [Презентация (PowerPoint)](presentation.pptx) · [Заметки](notes.md) · [Все 60 генераций и оценки](results/samples.csv)

## Запуск

Склонируйте репозиторий или распакуйте ZIP из меню Code. Откройте терминал в корневой папке проекта и выполните

```console
python experiment.py
```

Подойдёт Python 3.10 или новее. Основной запуск работает офлайн на стандартной библиотеке Python. Он обучает обе модели с нуля на сохранённых токенах, генерирует 60 ответов, присоединяет сохранённые оценки по анонимным идентификаторам и проверяет SHA-256 каждого текста. Запуск проверен с Python 3.13.16.

Программа запишет таблицу по всем попыткам и итоговые показатели в папку `results`. Чтобы записать результат отдельно, выполните `python experiment.py --out repeat`.

| Показатель | Биграммы | Триграммы |
|---|---:|---:|
| Есть фраза из корпуса длиной от 4 слов | 17/30 | 30/30 |
| Полная копия предложения | 0/30 | 9/30 |

## Файлы и поля

- `corpus.jsonl` содержит 500 предложений из 102 статей. Каждая строка хранит идентификатор S, URL, дату публикации из адреса, заголовок, порядковый номер сегмента в статье, исходный текст и список токенов.
- `experiment.py` обучает модели и считает показатели. `order` — порядок модели (2 или 3), `seed` — начальное значение генератора (0–29), `words` — длина без пунктуации, `stop` — причина остановки (`EOS` или `limit`).
- `ratings.csv` хранит оценки одного ИИ-разметчика по всем 60 текстам. `coherence` — связность от 0 до 2, `syntax` — завершённость последней конструкции от 0 до 1. В `comment` дано пояснение.
- `results/samples.csv` содержит тексты и показатели. `copied4` означает совпадение последовательности из четырёх слов с корпусом, `exact` — совпадение всех слов, `repeated2` — повтор пары слов внутри текста. `source4` и `source_exact` указывают на пример из корпуса. `correct_end` требует одновременно `stop=EOS` и `syntax=1`.
- `results/summary.json` содержит агрегаты. `coherence_hist` перечисляет количества оценок 0, 1 и 2. `rare_contexts` и `single_successor` считаются среди контекстов только из слов или чисел. Продолжения при этом могут включать знаки пунктуации и EOS.
- `results/transitions.jsonl` хранит для каждого шага контекст, выбранный токен, частоты и число различных продолжений. Последняя запись отражает решение об остановке. При `limit` выбранное слово не добавляется в результат.

Файлы CSV используют UTF-8 с BOM и разделитель «точка с запятой».

## Независимая оценка

Для повторной разметки выполните `python experiment.py --blind --out review`. Программа перемешает тексты и скроет модель и причину остановки. В `review/blind.csv` заполните поля `coherence`, `syntax` и `comment`. Колонки идентификатора, текста и контрольной суммы оставьте исходными. Затем выполните

```console
python experiment.py --ratings review/blind.csv --out reviewed
```

Связность равна 0, если смысл целого восстановить не удаётся, 1 — если осмыслены только отдельные фрагменты, 2 — если прослеживается одна мысль. При оценке окончания допустимы самостоятельные назывные предложения. Обрыв, несогласованная концовка, незакрытая цитата или отсутствие слов дают 0. Отдельная ошибка внутри высказывания допускает 1 за завершённость последней конструкции. Факты спорта в эти две оценки не входят.

## Повторный сбор корпуса

Для основного запуска данные уже включены. Если нужен повторный отбор из исходного архива, скачайте `lenta-ru-news.csv.bz2` из [выпуска v1.1 архива Lenta.Ru-News-Dataset](https://github.com/yutkin/Lenta.Ru-News-Dataset/releases/tag/v1.1) и установите NLTK с проверенной версией.

```console
python -m pip install nltk==3.10.4
python -m nltk.downloader punkt_tab
python prepare_corpus.py lenta-ru-news.csv.bz2 --out rebuilt.jsonl
```

Архив читается в исходном порядке. Фильтр оставляет точное значение рубрики «Спорт». Из тела каждой уникальной статьи берётся до пяти первых подходящих предложений. Токенизатор предложений — русский Punkt, токенизатор слов — RegexpTokenizer из NLTK. Правило токенизации записано в `prepare_corpus.py`. Порог — четыре слова или числовых токена и хотя бы одна русская буква. Заголовки, HTML, ссылки, неоднозначные внутренние точки и другие внутренние конечные знаки отсекаются. Дубли определяются после удаления пунктуации и приведения к нижнему регистру. Набор закрывается на 500-м предложении. Это последовательная историческая выборка за 17 февраля — 27 марта 2000 года.

SHA-256 итогового `corpus.jsonl` — `b49b6c087d0c65de19c291b462224705a1a23001488cb682e6477b6d962a3d3d`. SHA-256 использованного архива данных NLTK `punkt_tab.zip` — `e57f64187974277726a3417ca6f181ec5403676c717672eef6a748a7b20e0106`. Ссылки на публикации Lenta.ru сохранены для каждого предложения.
